# Unit Converter — Pytest

A small Python project demonstrating automated testing with **pytest**.

### What is covered
- Fixtures and fixture parametrization
- `@pytest.mark.parametrize`
- Dynamic test parametrization with `pytest_generate_tests`
- BFS and DFS algorithms
- Exception handling with `pytest.raises`
- Floating-point comparisons with `pytest.approx`

### Run tests

```bash
pip install -r requirements.txt
pytest -v
